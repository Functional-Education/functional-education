Milestone 3 prototype

Recursive thinking with functional blocks

Learn the basics of recursive functions without mutable data by assembling the key pieces of a correct solution.

Goal

Understand how a recursive algorithm stops and how it reduces the problem at each step.

Key idea

A recursive function has a base case and a recursive case. The base case stops the process, and the recursive case calls itself on a smaller input.

Functional style

No mutation. We create a new result from the current value and the recursive result.

Mini theory

1

Base case: stop when the problem is small enough.

2

Recursive case: work on a smaller input.

3

Combine: use the recursive answer to build the final result.

Main learning activity

Build the recursive solution

Arrange the blocks in the correct order to define a recursive function for the sum of the first n natural numbers.

Problem

Write a recursive function that returns the sum of all numbers from 0 to n.

What to look for

Correct base case, recursive reduction, and final combination.
